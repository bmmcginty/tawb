TAWB content coverage

This page carries every kind of content TAWB's extractors, views, and Lynx interface claim to support. It is served over loopback http like an ordinary page, talks to nothing, and changes nothing until a control is pressed.

Read it in each browser and in each interface, and cycle the four views with \. The sections are numbered C01 onward and each control has a stable name, so a reader can check them one at a time and a test can assert them by name.
